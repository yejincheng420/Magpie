# 0.6.9 Beta2：刷新设置布局与文案

日期：2026-10-02。起点 `b01299ad`，分支 `fix/069-beta2-refresh-layout`。维护者要求移除截图中的重复保存说明，将刷新设置的补充说明改为简短陈述，并把重复帧检测移入此区域的高级选项。

## 修改

- 重复帧检测从主页移至“帧率与刷新 → 高级选项”，保留从不、动态、总是三种选择和原全局配置字段。说明明确“检测并跳过相同画面，全局生效”。
- 配置页绑定原全局设置，切换模式继续处理动态检测统计；全局变更事件同步主页上的统计控件状态。
- 简体中文、繁体中文和英文说明只陈述控件用途，删除源应用帧率否定句、保存值不变的补充说明及后端执行细节。
- 配置页不再重复显示“修改自动保存；重新启用缩放或使用保存并重启后生效”。原配置上限和生效目标的状态说明仅在适用时显示，并使用简短陈述。
- 三项帧率保留 15–360 FPS、整数、普通步进 1。刷新策略、检测算法、配置结构和恢复默认范围沿用现有行为。

## 验证与交付

源码绑定及三语资源检查、相关配置回归、完整 Release x64 编译、编译后的 XAML／PRI、运行包校验与原生窗口启动按本轮修改验证。实际结果和准确构建提交以 `release/v0.6.9-beta2/BETA2-REFRESH-LAYOUT-PACKAGE-AUDIT.json`、`BETA2-REFRESH-LAYOUT-DEPLOYMENT-AUDIT.json` 为准，校验通过后才生成审计。

提交前完整 Release x64 编译通过，编译生成的配置页包含新的检测项绑定与条件说明可见性绑定；45 项三语 PRI 文本逐一与源码一致。2,053 项刷新检查、108 种生产视图模型组合，以及 181 项光标策略、195 项生产配置、15 项输入采样回归通过。

运行目录继续覆盖 `release/v0.6.9-beta2/Magpie-Experimental-x64/`；修改前的完整版本保留于 `release/archive/v0.6.9-beta2-before-refresh-layout-b01299ad/`，配置快照位于 `backups/069-beta2-refresh-layout-before/`。本轮只进行本地部署。
