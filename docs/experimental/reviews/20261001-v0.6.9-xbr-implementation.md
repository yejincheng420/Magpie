# 0.6.9 xBR 实施记录

日期：2026-10-01（Asia/Shanghai）。开发分支：`feature/xbr`。基线：`experimental@38416983`。

## 已接入范围

- 标准 xBR LV2：固定 2×、3×、4×，共用 `xBR_LV2_Common.hlsli`。
- xBR NoBlend：固定 3×，Point + Clamp，只暴露上游实际读取的 LV2 边缘系数。
- xBR Hybrid：固定 2×，保留 xBR GPL-2.0-or-later 与 Reverse-AA BSD 声明；gamma 域算法仅用于 SDR，HDR 兼容模式回退到 Point 2×。
- 五个效果均使用独立 `xBR\\...` ID，并接入工程复制清单、当前更新器文件清单、Effect Protocol、双语 Effect Catalog 和参数资源。
- xBR 与 xBRZ 保持独立分类；没有增加 Freescale、LV3、MLV4、Super-xBR 或历史版本入口。

## 参数决策

- 标准 LV2 暴露 `Y Weight`、`Eq Threshold`、`Lv2 Coefficient` 和 `Preserve Small Details`。
- 未暴露上游声明但当前路径没有读取的 `Lv1 Coefficient`。
- NoBlend 只暴露 `Lv2 Coefficient`；所选 Corner A 路径没有读取 `Eq Threshold`。
- Hybrid 不开放 gamma 常量，避免把未经验证的颜色空间假设变成用户设置。

## 当前验证边界

已完成 JSON / RESW / 工程 XML 解析、Effect Catalog 一致性检查、文件清单与 ID 静态核对，以及 `git diff --check`。本记录对应的最终提交没有生成 Release、安装包或部署结果。

以下项目明确留给 0.6.9 beta1 的构建与验收会话：实际 EffectCompiler Shader 编译、Release x64 构建、安装/更新/卸载、真实 GPU 与 Magpie UI、参考图误差、NoBlend 调色板断言、HDR 边界、画质和性能矩阵。未完成这些项目之前，不宣称新增 xBR 的性能或画质优于 xBRZ。
