# 0.6.9 Beta1 启动异常

2026-10-01 17:16（Asia/Shanghai）的三次用户启动均记录 `App.cpp` 未处理异常 `0x802B000A`；Windows Event 1000 对应 `Windows.UI.Xaml.dll`、`0xC000027B`。同时出现的 Screenshot 热键注册失败 `1409` 与致命 XAML 异常分开处理。

新加入的快捷键清除按钮在 `ShortcutControl.xaml` 引用 `SubtleButtonStyle`。该样式没有在应用资源或当前实际使用的 Microsoft.UI.Xaml 2.8.7 Generic.xaml 中定义。XAML 编译和资源存在检查不会解析所有运行期样式依赖，计算管线回归也没有加载原生主页。

修复清除按钮：使用默认 Button 样式，显式设置透明背景／边框，保留原来的图标、布局和事件处理，移除未定义的 StaticResource 引用。未处理异常的日志同时增加 XAML 错误详情，保留原 HRESULT，并避免获取详情失败覆盖原始错误。

同版本 Beta1 更新前的程序、ZIP、符号、构建记录及启动日志保存到 `release/archive/v0.6.9-beta1-before-startup-fix-ee3d6ee9/`。用户当前配置另行保存，不删除或重置。

本次完整编译、打包校验与实际启动结果以 `release/v0.6.9-beta1/STARTUP-FIX-AUDIT.json` 为准。原始启动日志、转储分析和验证材料保存在 `.tools/069-beta1-startup/`；原生启动验证与此前 CPU/WARP／NGX 测试的证据范围分开记录。
