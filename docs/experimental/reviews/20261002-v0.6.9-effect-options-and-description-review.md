# 069：效果组菜单与效果器说明实施记录

日期：2026-10-02。源码检查基线：`experimental` / `764b04d5`。菜单参考已部署 Beta1 fix3 的 `3297e648`；普通按钮外观参考当前 Beta2。

源码实现、逐项说明审查和本记录中的自动验证已完成。整项目编译、安装包更新、实际主窗口交互与目标内容实测仍属于后续 Beta 验收。

## 菜单实现

页头改为一个纯文字“其他选项”入口，直接弹出单层菜单：导入、导出、配置文件夹、分隔线、重置。导入、导出、重置沿用 Beta1 图标，新增文件夹图标；四项继续连接原动作。

入口使用命名的 `DefaultButtonStyle` 派生样式，避开 PageFrame 的固定图标宽度。高度沿用旧入口的 `PaneToggleButtonHeight`，原生 WinUI 测得 **36 DIP**；宽度按文字自适应。保持当前 12 DIP 字号、6/4 内边距、中性填充、零边框和系统焦点视觉。PageFrame 的居中位置与共享资源未改。

已迁移所有 19 个语言资源文件中的对应 Content/Text 键，保留既有翻译；18 个受支持语言有完整入口与菜单项资源。简中入口为“其他选项”，英文为“Other options”。配置目录打开失败时的标题同步改用 `/Text`，避免资源键迁移后反馈丢失。

配置文件夹继续使用当前 `AppSettings::ConfigDir()`。导入、导出取消仍直接返回；重置继续使用原确认对话框且默认按钮为取消。实际文件对话框和重置操作未在用户配置上执行。

## 主要内容修订

| 项目 | 当前说明与依据 |
| --- | --- |
| 列表摘要 | 简中最长从 114 字缩短到 27 字；英文最长 55 字。用途先出现在摘要，必要限制放在详情。仍允许选择器在窄布局中省略单行文本。 |
| DLSSNR | 补充 1～3 次串行处理、独立风格／强度、总变化只在全部处理后应用一次。SDR 细节控制需要启用输入分辨率调整；HDR 下该组控制不可用。区分单次直通回退与多次失败拒绝，以及实时和重启生效参数。依据 MultiPass、Filter、Parameters 和工厂实现。 |
| DLSSNR 兼容列表 | 旧“615 驱动、RTX 50 原生、旧代替换 DLL”来自历史用户提供的项目口径，本轮没有可引用的官方 DLSSNR 支持表。当前产品文案改为实际功能初始化要求，历史记录仍保留；不将该表写成官方普遍保证。 |
| DLSS SR | 保留当前 Balanced／Preset J 默认与未提供 L／M 选择的事实，不推断未测模型的画质收益。依据 `DLSSSRUpscaler.cpp`。 |
| 时序超分 | 说明外部捕获的运动估计和深度局限，不等同游戏内集成。FSR3／4、XeSS 的每轴 1×～3× 限制来自当前本地实现；FSR2 没有相同的本地 3× 检查。 |
| 限帧与补帧 | 新配置指向“帧率与刷新”；明确基础帧率、理论显示倍率与实际能力约束。列表位置不改变调度阶段，帧同步管理统一目标。 |
| XeSSFG | 保留默认 2×、AMD 光流、质量；非 Intel 3×／4× 明确属于本项目实验兼容路径。NVIDIA 光流仍限定于当前 2× 路径。 |
| RTX Video | Denoise／VSR 的四档强度可实时切换；模型准备可能增加暂时开销。HDR 四个参数也可实时调整。依据各后端的 ApplyMode 与参数应用代码。 |
| FSRCNNX | 当前两项主要区别为通用与 LineArt 训练权重，移除笼统“网络规模不同”家族说明。 |
| SMAA | jitter 译为采样抖动；NoJitter 仍用帧历史，不能归成空间方案。T2x／4x 保留捕获帧近似的实验范围。 |
| HDR | 普通 SDR 兼容路径提醒高光、颜色和渐变；Bicubic 保留浮点路径，NIS 保留待验证的颜色处理条件，xBR Hybrid 明确 HDR 时只做最近邻回退。 |

推荐标签共调整 **39 项**。当前 16 项“优先尝试”、130 项“特定场景推荐”、14 项“进阶／实验”、2 项“调试用途”。标签表示尝试场景和设置复杂度；模型规模与处理成本另行说明，未作为本机画质排名。CuNNy、NNEDI3 等较大网络不因计算量而自动标为实验；时序适配、DLSSNR、补帧与手动颜色流程保留进阶条件。

## 外部资料核对

外部资料用于解释算法输入和官方条件，本项目安装版本的能力仍以本地源码和运行库检查为准。当前上游能力不自动扩大本地界面选项。

- [AMD 时序超分集成说明](https://gpuopen.com/manuals/fidelityfx_sdk/techniques/super-resolution-upscaler/)描述运动向量、深度和采样抖动等输入；本项目从捕获图像估计这些辅助信息，不能据此宣称原生集成的画质。
- [Intel XeSSFG 开发说明](https://github.com/intel/xess/blob/main/doc/xess_fg_developer_guide_english.md)的非 Intel 官方路径最多生成一个中间帧；本项目额外的 3×／4× 兼容单独标为实验。
- [NVIDIA RTX Video 说明](https://docs.nvidia.com/maxine/vfx/1.2.0.0/Filters/VideoSuperResolution.html)和 [RTX Video FAQ](https://nvidia.custhelp.com/app/answers/detail/a_id/5448/kw/command/related/1)用于核对视频增强用途；本地档位映射、参数生效和颜色转换以当前适配器为准。
- [Anime4K](https://github.com/bloc97/Anime4K)、[CuNNy](https://github.com/funnyplanter/CuNNy)、[FSRCNN](https://github.com/igv/FSRCNN-TensorFlow)和 [Magpie prescalers](https://github.com/hauuau/magpie-prescalers)用于核对来源和素材域，安装的变体、尺寸与参数逐项记录在当前审查数据中。
