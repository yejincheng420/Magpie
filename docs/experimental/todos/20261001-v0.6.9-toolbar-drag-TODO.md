# 069 To do - 工具栏拖拽与上下停靠

创建日期：2026-10-01（Asia/Shanghai）。计划版本：`0.6.9`。
状态：源码实现和 CPU / Dear ImGui 自动回归已完成，已合并回 `experimental`；Magpie Release 编译、部署、原生 GUI / 实际 GPU 验收交由 069 beta1 独立会话。

关联需求：[Issue #50：希望支持工具栏框拖拽位置的功能](https://github.com/SAOG0721/Magpie/issues/50)。Issue 主诉为工具栏遮挡内容，希望允许拖动或选择显示位置；评论另提到参数面板鼠标穿透，已有“参数调整焦点切换”回复，本 TODO 聚焦工具栏位置。

## 1. 已确认的需求

- 直接拖住工具栏上的**专用拖拽柄**移动工具栏，不增加“点击移动后进入调整模式”的步骤。
- 工具栏可在顶部、底部停靠，并沿所在边缘左右移动；拖动过程中可以从顶部移到底部或反向移动。
- 拖动时，在输出视口顶部、底部显示**蓝色提示横条**，告诉用户可停靠的位置。
- 窗口模式下，专用拖拽柄移动工具栏；工具栏其他空白区域仍用于移动整个输出窗口。
- 窗口模式、全屏模式分别记住“顶部 / 底部”。左右位置不持久保存，只在本次运行期间保留；每次新运行默认水平居中。
- 没有独立应用配置时使用默认配置保存上下位置；已创建独立应用配置时，按当前匹配的应用配置保存上下位置，窗口 / 全屏仍分别记录。

## 2. 交互细则

### 2.1 拖拽柄与原有操作

- 在工具栏提供可辨识的专用拖拽柄，悬停提示“移动工具栏”，并提供适当的移动光标。
- 按住左键并开始拖动后，工具栏跟随鼠标；保持按下点相对工具栏的偏移，避免开始拖动时突然跳位。
- 普通按钮、帧率区域和拖拽柄的命中范围明确区分，不因点击按钮而移动工具栏。
- 窗口模式下，拖拽柄不返回移动整个输出窗口的标题栏命中结果；剩余可拖动空白区域继续保留原行为。
- “固定工具栏”继续表示始终显示，不把它解释为锁定位置；已固定和自动隐藏状态下均可使用拖拽柄。

### 2.2 蓝色提示条与停靠

- 仅在有效工具栏拖动期间显示顶部、底部半透明蓝色横条；靠近某条时加深高亮，并显示当前横向落点的停靠预览。
- 顶部、底部指工具栏所在的输出视口边缘。窗口模式提示条跟随输出窗口内容区域，全屏模式提示条跟随当前输出视口。
- 释放鼠标时，若位于有效提示范围，提交对应顶部 / 底部及横向位置；工具栏完整宽度必须处于视口范围内。
- 在中间等无效区域松手，恢复拖动前的停靠位置和横向位置，不保存该次拖动。
- 捕获丢失、切到其他应用、停止缩放或其他输入取消时，取消拖动并清除提示条，不把取消误当作有效释放。
- 蓝条和落点预览只负责绘制，不扩大正常工具栏命中范围；拖动期间由已开始的鼠标捕获接收移动 / 松开，避免操作穿透到游戏。
- 拖动期间保持工具栏可见，完成或取消后恢复原有固定 / 自动隐藏状态。

### 2.3 顶部与底部布局

- 两种停靠均支持沿边缘左右移动，坐标按当前工具栏实际宽度和视口尺寸限制，包含新增拖拽柄的宽度。
- 底部停靠同步适配圆角裁剪、工具栏内容的纵向偏移、边缘按钮点击和自动隐藏距离计算。
- 底部按钮的菜单 / 提示优先向视口内部展开，不能被屏幕下缘裁掉。
- DPI、输出尺寸或显示器变化后，保持上下选择并将本次运行的横向位置限制到有效范围；水平居中使用当前实际宽度计算。

## 3. 保存规则与运行生命周期

| 场景 | 上下位置 | 左右位置 |
| --- | --- | --- |
| 无独立应用配置：窗口模式 | 保存到默认配置的窗口模式字段 | 仅本次运行保留；新运行居中 |
| 无独立应用配置：全屏模式 | 保存到默认配置的全屏模式字段 | 仅本次运行保留；新运行居中 |
| 匹配独立应用配置：窗口模式 | 保存到该应用配置的窗口模式字段 | 仅本次运行保留；新运行居中 |
| 匹配独立应用配置：全屏模式 | 保存到该应用配置的全屏模式字段 | 仅本次运行保留；新运行居中 |

- 持久化数据仅需要两个有限值字段：窗口模式 `Top / Bottom`、全屏模式 `Top / Bottom`；不持久保存水平坐标、水平比例或任意纵向坐标。
- 缺少字段的旧配置和非法字段安全回落到顶部，水平位置在新运行开始时居中。
- 新增 / 复制应用配置时按既有配置复制流程初始化两个上下字段，之后独立保存；切换应用不得相互覆盖。
- 在有效松手且上下位置确实变化时，保存当前模式的上下字段。仅横向移动不触发工具栏位置写盘；无效释放和取消不写盘。
- 保存只更新本次匹配配置、当前模式的上下字段，保留另一模式和其他最新配置修改。应用配置删除、重排或运行结束后，过期保存回调不得写入其他应用或默认配置。
- 本次运行的横向位置放在运行状态中，不复用现有通用浮窗位置序列化去意外保存左右位置。
- 隐藏 / 重新显示工具栏不重置本次运行的横向位置。内部资源重建或受控重启需要沿用已有会话状态恢复机制；用户停止后重新启用、重启程序属于新运行，水平位置恢复居中。

## 4. 当前代码落点与实施约束

以下是 2026-10-01 本地检查的接入点，执行时复核最新工作区：

- `src/Magpie.Core/ImGuiImpl.cpp / .h`、`CursorManager.cpp`：复用按下 / 松开配对、鼠标捕获、输入取消和成功呈现后的命中范围更新。蓝条不得成为拦截游戏输入的整屏窗口；拖动过程中要持续刷新，不依赖游戏产生新画面。
- `src/Magpie.Core/include/ScalingOptions.h`：传入当前匹配配置的窗口 / 全屏上下设置，并在需要时扩展运行会话状态；持久上下字段与运行期左右状态分开。

- `src/Magpie/ScalingService.cpp`：按当前应用配置加载上下设置，并提供只更新对应上下字段的保存路径。现有 `options.save` 仅回写全局 `OverlayOptions`，不能直接用它替代应用配置保存。
- `src/Magpie/Resources.language-*.resw`：补齐拖拽柄提示，并调整首页“工具栏位于输出窗口顶部”的描述，覆盖英 / 简中 / 繁中。
