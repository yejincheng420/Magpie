关联需求：[Issue #34：允许清除快捷键](https://github.com/SAOG0721/Magpie/issues/34)。

## 1. 目标与范围

允许用户解除不需要的快捷键，释放被占用的键盘组合。清除只解除该功能的快捷键绑定，功能本身和按钮入口继续可用。

- 工具栏快捷键设置的六个子项提供行内垃圾桶：工具栏状态切换、性能监测、实时参数面板、对比、截屏、固定工具栏。
- 快捷键编辑弹窗统一提供清除入口，覆盖上述六项及全屏缩放、窗口化缩放，共八项。
- 全屏缩放、窗口化缩放的设置行沿用现有编辑入口，通过弹窗清除。
- 本轮不增加“一键清空全部”或“恢复全部默认值”，不更改现有默认组合键。

## 2. 用户交互

### 2.1 工具栏设置行

展开首页“工具栏快捷键设置”后，每行右侧按以下顺序排列：`[当前快捷键＋编辑图标] [垃圾桶]`。

- 垃圾桶为独立按钮，放在现有快捷键编辑按钮右侧；图标风格及尺寸沿用现有控件，点击区域满足正常按钮操作需求。
- Tooltip 为“清除快捷键”，辅助功能名称应能识别清除的是哪一项快捷键。
- 单击立即解除该项绑定并通过现有配置保存流程保存，不增加二次确认。
- 清除后，编辑按钮中的键帽替换为“未设置”，编辑图标保持可用。
- 已清空时垃圾桶保持原位并禁用，避免行宽和按钮位置跳动。
- 处于冲突或注册失败状态的已有绑定同样允许清除。

### 2.2 快捷键编辑弹窗

弹窗底部按顺序显示：`保存｜清除｜取消`，沿用现有保存按钮的主要操作样式。

- “保存”：保存当前有效的新组合键，继续执行合法性与冲突检查。
- “清除”：解除当前已保存的绑定，保存空值并关闭弹窗；不是仅清空正在录入的键帽，也不要求再点击“保存”。
- “取消”及现有取消关闭行为：放弃本次录入，保持打开弹窗前的绑定。
- 当前已保存的绑定为空时，“清除”禁用；已有绑定时，即使正在录入的组合不合法或有冲突，“清除”仍可用。
- 从“未设置”进入弹窗时应显示正常空状态，不显示无效快捷键警告；录入有效组合后允许保存。
- 空快捷键不能通过普通组合键合法性校验被判为错误；清除通过明确的按钮操作提交。

## 3. 配置与运行合同

### 3.1 区分缺失与主动清空

沿用现有快捷键数值编码，全部修饰键关闭且键码为 `0` 的空绑定编码为 `0`。

| 配置状态 | 加载行为 |
| --- | --- |
| 某快捷键字段不存在 | 为该项补入既有默认组合，兼容旧配置和后来新增的快捷键。 |
| 字段存在且数值为 `0` | 用户主动解除绑定，保持“未设置”。 |
| 字段存在且为有效非零数值 | 保留用户设置，沿用合法性与注册检查。 |
| 字段类型错误或数值损坏 | 沿用配置校验及恢复流程，不解释为用户主动清空。 |

- 首次运行仍初始化既有默认快捷键。
- 序列化必须写出主动清空的字段和值 `0`，不能删除该字段。
- 正常退出、重启以及涉及快捷键的配置迁移、导入导出和恢复路径均保留显式 `0`。
- 不能再仅凭 `IsEmpty()` 为已加载的快捷键补默认值；需要在加载阶段保留字段存在性，或先初始化默认值再由明确存在的字段覆盖。
- 保存失败沿用现有配置写入失败提示与恢复机制，不因快捷键清除绕过错误处理。

### 3.2 解除注册与同步显示

- 两个清除入口使用同一条设置更新路径，触发现有 `ShortcutChanged` 和配置保存流程。
- 立即注销该动作的原有全局快捷键；键盘钩子同样不再匹配该动作。
- 空绑定是正常的未注册状态，清除该动作的错误标记，不调用空快捷键的注册校验，不输出“注册热键失败”。
- 重新设置时恢复现有合法性、冲突及注册失败处理，不影响其他动作的绑定。
- 运行中的工具栏及实时参数面板快捷键提示同步更新；未设置时只保留功能名称，不拼接空括号或旧组合键。
- 弹窗关闭时正确释放录入用键盘钩子并恢复正常输入处理，覆盖保存、清除、取消及异常关闭路径。
