## 1. 已确认的布局

- 标题行左侧保持“效果组”；同一行右侧按顺序显示 **导入、导出、配置文件夹、重置**。
- 四项采用紧凑文字按钮，保持现有 WinUI 主题、悬停、按下和键盘焦点反馈；移除页面标题的 `…` 与对应菜单。
- 使用短标签“导入”“导出”“重置”，不在标题行扩写成“导入效果组”“导出效果组”“重置效果组”。
- **“＋新建效果组”保留在整个效果组列表下方的右侧**，沿用原来的位置和强调按钮样式，随列表滚动；不移到标题行，也不在每张效果组卡片下重复放置。
- 标题操作保留在固定页头；列表及新建区域使用现有内容滚动区。

布局示意：

```text
效果组                           导入  导出  配置文件夹  重置

[效果组 A                                              ]
[效果组 B                                              ]
[效果组 C                                              ]

                                          [＋新建效果组]
```

## 2. 功能语义

| 操作 | 行为 |
| --- | --- |
| 导入 | 沿用现有 JSON 文件选择、校验、迁移与追加导入路径；重复名称继续自动添加序号并提示 |
| 导出 | 沿用现有保存文件对话框，导出全部当前效果组，不扩大为整份应用配置导出 |
| 配置文件夹 | 打开当前实际生效的配置目录，路径来自 `AppSettings::ConfigDir()`，兼容普通模式与便携模式 |
| 重置 | 沿用当前确认弹窗及取消默认选项；确认后删除全部当前效果组、恢复默认效果组，自定义程序配置回退到全局默认效果组 |
| ＋新建效果组 | 沿用现有创建空组、生成不重复名称、展开并自动打开重命名、保存的流程 |

配置目录通过运行时路径解析，不写死用户目录、程序目录或旧版配置位置。打开失败时使用现有错误提示机制说明失败及目标路径。

## 3. 按钮消失的源码线索

- [ScalingModesPage.xaml](../../../src/Magpie/ScalingModesPage.xaml) 列表使用 `Padding="0,0,0,44"`，其后新建按钮容器使用 `Margin="0,-36,0,0"`，通过负边距占用列表底部预留区域。
- Beta1 fix2 提交 `af548e7c8458394b6ca1477c132e4b0017599a56` 在 [SimpleStackPanel.cpp](../../../src/Magpie/SimpleStackPanel.cpp) 的测量及排列阶段新增了零尺寸过滤：主轴 `DesiredSize <= 0` 时跳过该子项，用于消除参数面板隐藏容器的多余间距。
- 独立原生 XAML 测试使用实际 `AccentButtonStyle` 和生产 `SimpleStackPanel` 复现了此组合：旧容器 `DesiredSize.Height=0`，按钮 `ActualHeight=0`，确认测量／排列回归。
- 修复移除新建容器的 `-36` 上边距，保留列表原有 `44 DIP` 动画补偿留白。新建区域按正常正高度参与测量、排列及内容范围，仍在整个列表下方右侧。
- 参数面板的零尺寸过滤有独立用途；本修复优先改正效果组页面布局，不通过整体回退该过滤恢复按钮。

## 4. 实施范围

- `src/Magpie/ScalingModesPage.xaml`：标题行四个操作、按钮样式及列表下方新建区域布局。
- `src/Magpie/ScalingModesPage.cpp/.h`：按需要增加打开配置目录的处理函数，保留现有新建与重置事件。
- `src/Magpie/ScalingModesViewModel.cpp/.h/.idl`：仅在选择 ViewModel 承接目录动作时修改；导入、导出复用现有入口。
- `src/Magpie/Resources.language-*.resw`：短标签、可访问名称及需要的目录错误提示，遵循现有语言与回退规则。
- 必要的原生 XAML 布局回归及本 TODO／索引状态。

[PageFrame.xaml](../../../src/Magpie/PageFrame.xaml) 当前对标题操作中的按钮提供固定图标按钮宽高和零内边距。效果组页面应使用局部文字按钮样式，显式处理自动宽度、内边距和间距，避免“配置文件夹”被固定宽度截断；保留其他页面的标题操作外观。

资源绑定需核对从 `MenuFlyoutItem.Text` 切换到按钮内容后的属性映射，避免沿用不适用的 `.Text` 资源而出现空白按钮。标题操作按用户确认保持同一行，最小窗口和较长语言文案须测量验证，不自动改回更多菜单或采用此前未确认的第二行布局。
