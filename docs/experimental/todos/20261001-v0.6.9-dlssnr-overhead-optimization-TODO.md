## 1. 已确认目标与行为边界

用户已确认：Residual 饱和度、明度等参数控制全部 NR 完成后的总修正，统一调整一次。本清单覆盖重复运算、同步、资源和初始化开销；完整收益评估仍以 V 项验收为准。

目标管线：

```text
保留原尺寸输入 X
    ↓
D3D11：颜色准备 / 降采样一次，准备共用的推理尺寸引导
    ↓ 入口同步一次
D3D12：NR Pass 1 → 层间资源屏障 → NR Pass 2 → 层间资源屏障 → NR Pass 3
    ↓ 出口同步一次
D3D11：最终低分辨率输出 − 最初低分辨率输入
    → 总残差控制一次 → 残差升采样一次 → 加回 X → 输出端抗闪烁
```

- 总残差参考为最初低分辨率输入 `L0`，即 `LN − L0`；不是最后一层的局部增量 `LN − L(N−1)`。
- 高分辨率原图保留为最终基底；升采样对象为有符号残差。颜色控制继续在残差升采样之前执行。
- Multi Pass 保持 `1 / 2 / 3`，各层七个独立 NR 参数、Feature、参数块和时序历史继续独立。
- 降采样与残差重建的行为调整首先针对当前启用了输入分辨率调整的 SDR 路径。HDR FP16 当前不使用这套 SDR 缩放 / Residual 合同；不得未经验证直接套用 SDR 限幅、HSL 控制或纹理格式。
- 多层低分辨率直接串联及统一总残差控制会改变后续层输入和画面行为，不能作为与旧管线逐像素等价的优化。单层在相同算法、格式、边界和算术顺序下应保持原行为。
- 抗闪烁以 DLSSNR 原输入为基底，稳定全部 pass 的总修正，并保持在统一残差控制与原尺寸重建之后执行，见第 8 节。

## 2. 当前重复开销与目标计数

下表以三个 pass、一个新的有效捕获帧、正常推理、SDR 输入分辨率调整开启且宽高都实际缩小为基准。故障、重复帧复用、100% 与 HDR 路径须单独统计。

| 项目 | 当前三个 pass | 目标 | 前提 / 验收重点 |
| --- | --- | --- | --- |
| 颜色降采样 | 3 套，每套纵向与横向 2 次 dispatch | 1 套 | 低分辨率 NR 串联，保留原图基底 |
| 运动 / 深度 / 置信度降采样 | 3 次 dispatch | 同帧同尺寸 1 次 | 共用来源、缩放规则与有效区域 |
| 残差提取与色彩控制 | 3 次 dispatch | 1 次 | 使用 `LN − L0` 总残差 |
| 残差水平升采样 | 3 次 dispatch | 1 次 | 保留当前插值核和边界处理 |
| 残差垂直升采样与叠回 | 3 次 dispatch | 1 次 | alpha、限幅与输出格式正确 |
| D3D11 → D3D12 Signal / Wait | 3 组 | 入口 1 组 | 中间结果留在 D3D12 |
| D3D12 → D3D11 Signal / Wait | 3 组 | 出口 1 组 | 所有层完成后交付最终输出 |
| D3D11 Flush | 3 次 | 入口 1 次 | 覆盖颜色和引导准备的提交 |
| D3D12 ExecuteCommandLists | 3 次 | 集中提交 | 验证多 Feature 录制和提交行为 |
| 等待同一引导生产者 | 每层重复等待同一组同步点 | 链入口一次 / 同步点去重 | 同一 fence 取所需最大值，覆盖实际读取的资源 |
| 共用引导资源的可读 / COMMON 转换 | 每层各进出一次 | 链入口 / 出口各一次 | 层间保持有效可读状态 |
| 层间输入准备与输出回写 | 每层独立准备和交付 | 直接传递 D3D12 颜色资源 | 保留入口 / 出口必要的转换或复制 |
| 缩放常量上传 | 各层各阶段重复 UpdateSubresource | 共用 / 按变化更新 | 异步 GPU 生命周期与绑定正确 |

仅颜色、引导与残差外围计算的理论 dispatch 目标为 `18 → 6`；跨 API 交接目标为“三进三出 → 一进一出”。NR 推理仍是三次，其内部 dispatch 不包含在该计数中。这些是结构目标，不是已经测得的耗时或 FPS 收益。

`ID3D12CommandQueue::Wait` 与互操作 context Wait 是 GPU 队列依赖。当前命令槽复用另有 CPU fence 检查，只有旧任务未完成时才阻塞；不得把三组交接直接描述成每帧三次 CPU 阻塞。

## 5. P2：链入口缩放与出口总残差

- [x] R01：保留原尺寸输入和最初低分辨率输入 `L0`，入口只进行一次颜色准备 / Lanczos2 降采样；将必要的格式转换放在入口，复用当前 typed view 逻辑。
- [x] R02：各层 NR 在同一推理尺寸下直接串联，最后一层输出为 `LN`；首次新增层的默认参数、隐藏后恢复参数和层间输入修订继续正确。
- [x] R03：出口只提取一次有符号总残差 `LN − L0`，统一执行 Residual Multiplier、Saturation、Lightness、Shadow / Structure 与 Reflection / Glow 控制。
- [x] R04：保留低分辨率残差 FP16、Catmull-Rom 水平 / 垂直重建、原图叠回、原 alpha 与最终输出限幅；零残差必须返回原输入。
- [x] R05：移除逐层原尺寸重建和再降采样；把原尺寸层间纹理改为所需低分辨率资源，按缓存和时序使用需求设计容量。
- [x] R06：上一层 D3D12 输出直接作为下一层输入，减少层间 CopyResource；保证输入 / 输出格式、尺寸、读写分离和资源状态一致，不能假设 NR 支持原地读写。
- [x] R07：入口 / 出口仅保留必要复制；延续当前输出支持独立 UAV 时直接写出的快路径，不能将条件复制误统计为每层固定开销。
- [x] R08：链共用缩放中间纹理、残差纹理和常量信息；尺寸、比例与控制值不变时减少上传，保留正确 shader 绑定和在途任务生命周期。

## 6. P3：D3D12 集中调度与边界同步

- [x] S01：链共用 D3D12 队列、互操作 fence、事件和命令槽；每层只持有独立的 NR Feature / 参数 / 历史等必要状态。
- [x] S02：颜色和引导准备完成后，执行一次 D3D11 Signal、一次必要 Flush 和一次 D3D12 Wait；入口同步覆盖该帧所有实际消费资源。
- [x] S03：验证多个独立 DLSSNR Feature 在共用队列上的顺序录制 / 提交；优先评估一份 command list 内顺序 Evaluate，或带完整依赖的集中提交方案。验证前不假定该 DLL 已支持新方式。
- [x] S04：所有层完成后只执行一次 D3D12 Signal 与 D3D11 Wait，最终合成及外部抗闪烁遵循该输出依赖。
- [x] S05：共用引导只在链入口转为可读，在最后一层读完后转回交接状态；颜色资源只在实际读写角色 / API 边界需要时转换。
- [x] S06：保留层间输出写入 → 下一层读取的资源屏障与必要 UAV / 别名依赖；同一队列不等于可以删除资源依赖，不能只删除旧 Signal / Wait。
- [x] S07：命令槽复用统一检查整条链的完成值；保留在途命令 allocator / list、颜色及引导资源的保护，不得提前 Reset、覆盖或释放。
- [x] S08：链级统一 Drain 和共享资源释放，覆盖次数变化、resize、停止、设备失效、初始化部分失败及 Evaluate / 提交失败；保持整链失败可识别，不把部分成功当作完整输出。

## 7. P4：缓存、实时参数与初始化重复

### 7.1 缓存和参数更新

- [x] C01：Residual 参数改为出口控制后，保留有效 `L0` / `LN` 或等价原始总残差缓存；修改这些参数只重跑残差控制 / 重建 / 必要输出处理，不重新执行各层 NR。
- [x] C02：区分 NR 结果缓存与后处理缓存：NR 参数、上游输入修订、资源变化仍使相关层及其后续层失效；纯输出参数不再提高下游 NR 输入修订号。失败、reset 和重复帧行为分别覆盖。
- [x] C03：链入口统一判断整链完全未变化的重复帧；保留每层参数 / 输入修订记录，允许最后一层设置变化时复用前面仍有效的结果，避免过度失效或漏算。
- [x] C04：验证 DLL 的 NGX 参数保留 / 改写行为后，将固定标志、固定区域与未变化 NR 参数改为初始化 / dirty 更新；逐帧 reset、变化的资源指针、有效区域等仍按实际需要设置。前提不成立时记录结论并保留必要设置。候选已收口：各可选 DLL 尚无统一验证过的参数保持 / 改写合同，保留每次 Evaluate 的完整参数设置。
- [x] C05：修改 Residual 参数时清除外部抗闪烁历史，复用 NR 结果并重新处理输出；NR 参数或上游输入变化时重算受影响层并重置相应历史，捕获重置、尺寸变化和资源失效沿用完整失效规则。

### 7.2 初始化和资源创建

- [x] I01：同一 D3D11 设备共用公共计算着色器及编译结果，减少六个缩放 / 引导 / 残差 entry point 和必要格式转换 shader 的逐层编译与创建。
- [x] I02：将队列、fence、事件、命令环和公共常量缓冲的创建归属集中到链，记录初始化与次数重建的耗时 / 对象数；每层 Feature 创建仍保留。
- [x] I03：合并公共缩放 / 残差临时纹理的分配，以链内公共资源集合复用，按帧在途、独立历史与局部重算保留 L0 和各层输出；省去 100% 时未使用的中间 / 引导纹理，不引入跨设备或会话的纹理池。
- [x] I04：统一公共 SRV / UAV 与共享句柄映射的生命周期，避免每层为同一资源各建一套；复用以设备、格式、资源身份和代次为条件。
- [x] I05：诊断构建集中 timestamp query 解析、读回和汇总，仍能区分各层 NR 与链外围开销；普通构建维持详细采样关闭，不将此项列为默认每帧的大额收益。当前集中解析 D3D12 链总时间 / 各层 NR，外围 CPU 准备分开统计；完整 GPU 外围测量继续由 V07 验收。

## 9. 已共用 / 已有快路径与必须保留的工作

### 已共用或已缓存

- 光流估计由捕获帧的共享 Frame Guidance 服务产生，不是每层重新计算。
- D3D12 设备与 NGX Core 已共用；DLSSNR DLL 会话、Init / Shutdown 和兼容钩子已有共享所有权。
- Frame Guidance 服务已有同帧 / 消费者尺寸适配缓存；本轮 G 项针对 NR 内部再次适配及逐层资源包装。
- 单层引导 SRV 与共享资源已有身份缓存，不是每帧必定 Create / OpenSharedHandle。
- 100% 时颜色降采样已跳过；必要格式转换仍按输入格式执行。
- 输出符合独立 UAV 条件时，残差合成已有直接写出快路径。
- 重复捕获帧各层已有复用检查；C03 是提升到链级并细化失效，不是首次引入缓存。
- 外部抗闪烁已经位于整链输出端并只执行一次。

### 必须保留

- 启用三层时仍执行三次 NR Evaluate；不以合并提交代替各层实际模型处理。
- 各层独立 Feature、NR 参数、内部时序历史及必要 reset / 错误状态。
- 层间颜色写入到读取的依赖、入口生产完成依赖和出口消费完成依赖。
- 正确的 frameId、资源代次、有效区域、捕获重置、Zero / fallback 和上游输入修订传播。
- 等待 GPU 完成后复用或释放在途资源的生命周期保护，以及完整处理链的失败判定。
