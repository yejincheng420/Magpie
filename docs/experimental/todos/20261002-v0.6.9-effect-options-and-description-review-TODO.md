## 1. 已对齐的要求

### 效果组操作菜单

- 标题右侧保留一个文字入口，名称为 **其他选项**，只显示文字。
- 点击入口直接弹出单层菜单，沿用 Beta1 的下拉菜单结构及菜单项图标。
- 菜单顺序为 **导入 → 导出 → 配置文件夹 → 分隔线 → 重置**。
- 入口高度、垂直位置参考 Beta1 的旧入口；文字按钮宽度随内容调整，避免沿用固定图标宽度造成截断。实施前核对旧入口实际高度与资源值。
- 入口填充、圆角、零边框、悬停／按下／禁用／焦点反馈参考当前 Beta2 的普通操作按钮。
- 四项动作继续使用现有处理逻辑；配置文件夹指当前生效配置目录，重置沿用确认／取消对话框。

### 效果器说明

- 覆盖全部 **162 个内置效果器**的摘要、详情、推荐标签，以及 **8 个分类、17 个子分类、13 个家族、2 个子家族**的说明；核对自定义效果器的通用说明。
- 简体中文与英文同步 review、同步修订。关联参数和运行时行为作为说明准确性的核对依据。
- 逐项核对当前源码；涉及外部算法、硬件、驱动或运行库条件时，查证对应的官方资料并记录出处。
- 面向普通用户，优先说明 **用途、适用素材、变体差异、组合建议、必要限制**；列表摘要保持简短，详情根据效果实际需要展开。
- 技术实现、证据来源、历史审查过程和实测范围写入审查记录，产品说明保留影响用户选择与操作的信息。
- 重新评估推荐标签，区分适用场景、操作复杂度、性能开销与实验成熟度，避免将“大模型／成本高”直接等同于“实验”。
- 画质、帧率与延迟结论按实际证据表达；源码或目录校验不能替代目标内容实测。
