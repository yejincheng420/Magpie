## 3. DLSSNR 分组和进阶开关

### 配置页分列

| 列 | 内容 | 显示规则 |
| --- | --- | --- |
| 细节控制 | 输入分辨率开关／百分比、五项基础修正强度、光流方法／对应质量、“进阶调整”开关 | 依照当前有效路径和光流方法显示相关控件 |
| 进阶调整 | 色相变化保护、暗部保护、高光保护、局部失控压缩、大范围修正、细节修正、色度时域稳定、诊断视图 | 默认隐藏；由细节控制中的单个开关控制整列 |
| DLSSNR · Pass 1 | 既有 NR 参数、Multi Pass 和抗闪烁选项 | 保留既有字段与运行规则 |
| DLSSNR · Pass 2／3 | 对应层 NR 参数 | 仅显示已启用的层 |

- 原来的“展开保护控制”和“展开进阶控制”合并为一个“进阶调整”开关。
- 该开关只改变控件展示；收起不清空参数、不把非默认参数改回默认，也不关闭已配置的保护／压缩／稳定效果。
- 默认隐藏指新建或缺少展示状态时默认关闭；旧展示字段的兼容读取与清理只涉及布局状态，不能影响算法参数。执行时明确一个布局状态来源，避免两个旧开关继续互相控制。
- 不因为已有非中性数值自动展开进阶列。
- 当前残差控制依赖 SDR 输入分辨率调整路径，包含比例 `100%`；本轮不额外扩展至 HDR 或原先未启用残差重建的路径。
- 色度时域稳定依赖抗闪烁。依赖不满足时保留数值、禁止调节，并在参数名称的提示中说明原因；不能暗中开启历史累积。
- 进阶列启用／收起不触发额外 NR 推理，也不因单纯展开状态改变清除画面历史。

## 4. 参数名称悬停提示

- 面板常驻显示参数名称、当前数值及滑块／下拉／开关，不直接显示解释段落、范围和步进说明，不新增独立说明列。
- 鼠标停留于参数名称时显示提示；不要求用户悬停滑块数值、点击帮助按钮或先展开额外详情。
- 提示优先给出实际调节作用，再给出范围、默认值、步进；数值信息来自同一份参数元数据，防止文案与控件不一致。
- 示例：`减少原图深暗区域受到的修改。\n范围 0–1 · 默认 0 · 步进 0.05`。解释不直接重复“0 关闭，1 最强”作为全部内容。
- 无效／禁用控件的名称仍可查看提示，说明所需条件；运行时已有的实时生效、需重启、恢复默认等提示与新作用说明协调显示，不能互相覆盖。
- 移开名称、关闭浮层、隐藏分组或停止缩放时关闭对应提示；提示不挤动布局、不捕获滑块拖动、不扩大游戏输入拦截区域。
- 提示按所在屏幕／输出视口可用空间摆放，底部优先向上；限定宽度并换行，不能在窄屏下成为超屏长条。
- 配置页 XAML 与运行时 ImGui 共用参数作用信息及本地化数据；不继续将说明硬编码在 `Label` 的第二行。
- 补齐英文、简体中文、繁体中文。键盘与辅助功能沿用既有说明入口，不把鼠标提示作为唯一可访问的说明数据。

## 5. 统一残差算法与旧配置迁移

- 产品只保留现有新残差算法；删除旧 HSL 运行分支、颜色模式下拉框及依赖旧模式的显隐规则，不只是隐藏选择器。
- 旧 `residualColorMode` 为 0、为 1、缺失或非法时，均进入唯一保留的算法；旧选择标记只可作为兼容读取资料，不能继续改变渲染路径。
- 保留残差强度、明度／色度、变暗／变亮、保护、压缩、频率及稳定等已有合法数值；缺失参数使用各自既有默认值，非法数值沿用正常归一化规则。
- 保留原配置中的 NR 各层数值、层数、输入比例、光流和抗闪烁设置；不因为颜色模式迁移重置无关配置。
- 读取、导入、复制、导出、保存、重新打开以及运行时传参都使用一致结果；禁止主界面已迁移而后端缺字段又回到旧模式。
- 旧非默认颜色参数在新算法下可能呈现不同观感；用户已选择保留数值迁移，不保证像素级保持旧模式外观。当前使用说明可简短说明“旧参数值保留，画面表现可能变化”，无需讲解颜色算法名称。
- 全部默认参数仍应保留原始 NR 修正；总强度 0 回到原图、零残差保持原图、alpha 不改变、隐藏参数继续生效等合同保持。
- 纯后处理调参继续复用已有效的 NR 结果，正确更新必要重建及抗闪烁历史，不重新引入每次调参重复推理。
- 当前参数提示、效果目录、目录生成脚本、使用指南与后续更新清单移除颜色模式比较和单独强调 Oklab 的表述。保留技术实现名称及历史诊断证据，不能通过全仓字符串替换改写过去的测试结论。

- 顶部停靠上边贴齐、下方圆角；底部停靠下边贴齐、上方圆角。图标方向、按钮顺序和操作语义保持一致。
- 顶部／底部的按钮行、FPS、拖拽柄可见高度及边距对应；不以裁掉图标或高亮背景实现贴边效果。
- 菜单、子菜单和提示优先向输出视口内部展开，底部不得越出屏幕／窗口下缘；首次出现和长菜单同样检查。
- 检查贴边高亮、圆角、背景和命中范围使用一致缩放，特别覆盖 DPI 大于 100% 且输出窗口较小的情况。
- 保留固定／自动隐藏、底部唤出、拖动期间可见及按最后成功呈现范围命中的原有规则。

## 7. 工具栏水平居中吸附与青色线

### 吸附几何

- 对顶部和底部停靠目标使用同一水平居中轴：当前输出视口宽度为 `V`、工具栏实际宽度为 `W`，居中左坐标为 `(V - W) / 2`。
- 根据鼠标位置与抓取偏移计算**未吸附的工具栏位置**，再限制到视口内。不能用拖拽柄或鼠标所在位置代替工具栏整体中心。
- 当已有有效顶部／底部停靠目标，且工具栏未吸附中心相对输出视口中心的水平距离 `<= 12px`，将显示位置与落点预览吸附到精确水平居中。
- 吸附范围为中心左侧 12px 至右侧 12px，共 24px；`12px` 边界包含在内。按用户的 px 口径记录为输出画面的物理像素，不再乘 DPI 或工具栏缩放比例。
- 每次移动都用未吸附候选位置重新判定；越过 12px 即释放吸附，避免使用已吸附坐标造成“吸住后拖不出来”。不额外引入未约定的更大释放范围。
- 没有有效顶部／底部目标时不吸附；进入／离开目标区及时更新，实际拖动显示、预览与最终落点使用相同计算。
- 有效松手按当前吸附结果落点；无效区域松手、失去捕获、切换应用或停止缩放仍取消并回到拖动前状态。

### 青色居中提示

- 中央青色线表示当前工具栏已达到居中吸附条件，不能仅因鼠标经过中央就显示。
- 位于输出视口水平中心的竖线贯穿当前输出区域上下，宽 `2` 个物理像素；青色建议使用 `RGB(0, 255, 255)`。
- 全屏以当前工具栏所在输出视口为准；窗口模式以输出窗口内容区域为准，不跨越桌面、任务栏或其他显示器。
- 与现有顶部／底部蓝色提示条和落点预览同时工作，颜色承担不同含义；线条只绘制，不新增窗口、命中区或输入捕获。
- 线条的位置／宽度按实际像素检查，避免 DPI 放大成 3／4px，或因坐标不对齐出现意外粗细与抖动。
- 显示时机已确认：仅拖拽且正在居中吸附时显示，松手／离开／取消即消失；居中停靠后不保留常驻提示。

### 原保存规则

- 窗口／全屏上下位置仍按默认／应用配置分别保存；水平位置只在本次运行内保留，新运行默认居中。
- 单纯横向拖动或居中吸附不新增写盘；不要为了记住居中增加新的持久化位置字段。
- 同一次运行的资源重建、模式切换和受控重启沿用现有恢复规则。
